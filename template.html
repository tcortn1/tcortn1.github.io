Lending Genie Bench

Text2SQL · Databricks · DSPy · MLflow
In progress

Credit analysts ask questions like "which origination quarter defaults fastest?". Answering them correctly takes the right tables, the right metric definitions (PAR30, vintage, roll rate) and SQL that respects them. This project benchmarks Text2SQL approaches against Databricks Genie on a realistic lending portfolio.

  • Simulated lender with real statistical structure: a latent-logit default model with unobserved heterogeneity, an arrears Markov chain and sector macro shocks. No random rows.
  • Lakeflow pipeline (bronze → silver → gold) with business descriptions on every column, feeding both Genie and the agent.
  • DSPy agent: retrieve schema and definitions, generate SQL, enforce read-only guardrails, self-correct on errors. Served through MLflow.
  • Benchmark: 40 held-out questions scored on execution accuracy across 5 variants, including DSPy-optimised prompts and Genie.

Agentic Security Lab

Multi-agent · evaluation · safety by design

Can an LLM agent find vulnerabilities it was never programmed to look for, without being trusted on its word? This multi-agent loop runs against isolated Docker labs, and every finding has to be confirmed by code.

  • Orchestrated agents (recon, planner, validator) over a policy-bounded tool layer; only allowlisted local targets can be reached.
  • Two strategies, one benchmark: a deterministic heuristic planner vs. an LLM exploration agent.
  • Findings are only accepted on a discriminating signal; a 200 status or a generic success field is rejected as proof.
  • Execution-trace dashboard, Markdown reports, 69 tests.

Fine-tune & quantization benchmark

QLoRA · GGUF · deployment trade-offs

Which model should you actually deploy? I fine-tuned Mistral 7B for financial sentiment extraction, then mapped the accuracy vs. size vs. speed trade-off across five quantization levels.

  • QLoRA (4-bit NF4, r=16) on ~3,100 labelled financial news sentences, about 4 minutes on one A100.
  • Quantized to GGUF from Q8_0 down to Q3_K_M; every variant evaluated on the same 346-example held-out set.
  • Measured accuracy, macro F1, latency, throughput and size; served the winner through an API.

Surprise-gated agent memory

RAG · agent memory · evaluation

Store-everything memory bloats over time and fills up with outdated, contradicting facts. This memory layer only writes what is new or contradictory, and updates its beliefs instead of piling them up.

  • Four gates: an LLM noise filter, NLI-based contradiction detection, embedding novelty and belief strength.
  • Confirmations reinforce a belief; contradictions decay it until it is deprecated.
  • Evaluated on LoCoMo: 10 long conversations, 1,980 questions.
